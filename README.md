Beauty Hub

A full-stack beauty product library and management application designed to help users organise, browse and manage beauty products through an interactive web interface.

Beauty Hub evolved from an existing Java desktop application into a web-based system, introducing a React frontend, Node.js backend, REST APIs, user authentication and persistent SQLite storage.

Features

* User authentication and protected routes
* Beauty product library and management
* Product data retrieval and management
* Persistent SQLite storage
* REST API communication between frontend and backend
* Responsive user interface
* Automated and structured manual testing of core workflows

Running Locally

Prerequisites

* Node.js
* npm
* Git

Clone the repository

git clone [repository-url]
cd BeautyHub

Install dependencies

For the frontend:

cd frontend
npm install

For the backend:

cd ../backend
npm install

Start the application

Start the frontend:

npm start

Start the backend:

npm start

The application will then be available at the development URL provided by the frontend.

Authentication

Beauty Hub includes authentication and protected routes to control access to user-specific functionality.

The frontend communicates with the backend through REST API endpoints for authentication and application functionality.

Project Background

Beauty Hub originally began as a Java desktop application and was later developed into a web-based system.

The project provided experience across the full stack, including:

* Developing a React frontend
* Building backend functionality with Node.js
* Designing and consuming REST APIs
* Working with SQLite and persistent data
* Implementing authentication and protected routes
* Testing application workflows
* Connecting frontend, backend and database components
